Personvern

Dette nettstedet setter ingen informasjonskapsler, bruker ingen verktøy for trafikkmåling, ingen eksterne skrifttyper eller ressurser, og inneholder ingen skjemaer.

Hvis dere skriver til oss på contact@citso.eu, brukes meldingen deres kun til å svare dere; den blir verken overdratt eller videresolgt. Dere kan når som helst be om innsyn i dataene deres eller om at de slettes, på samme adresse.

GitHubs rolle

GitHub brukes kun til visning av dette offentlige nettstedet. Det mottar ingen data fra kundene våre: verken katalogdata, revisjonsresultater, rapporter eller meldinger. Produktet CITSO kjører i sin helhet hos kunden, offline, uten noen tilkobling til GitHub eller til noen annen nettjeneste.

Som enhver vertsleverandør kan GitHub av tekniske grunner logge IP-adressen til besøkende på dette nettstedet av hensyn til sikkerheten i tjenesten, i samsvar med sine egne retningslinjer.
