Απόρρητο

Αυτός ο ιστότοπος δεν αποθηκεύει κανένα cookie, δεν χρησιμοποιεί κανένα εργαλείο μέτρησης επισκεψιμότητας, καμία εξωτερική γραμματοσειρά ή πόρο, και δεν περιέχει καμία φόρμα.

Αν μας γράψετε στο contact@citso.eu, το μήνυμά σας χρησιμοποιείται μόνο για να σας απαντήσουμε· δεν παραχωρείται ούτε μεταπωλείται. Μπορείτε να ζητήσετε ανά πάσα στιγμή πρόσβαση στα δεδομένα σας ή τη διαγραφή τους στην ίδια διεύθυνση.

Ο ρόλος του GitHub

Το GitHub χρησιμοποιείται μόνο για την εμφάνιση αυτού του δημόσιου ιστότοπου. Δεν λαμβάνει κανένα δεδομένο των πελατών μας: ούτε κατάλογο, ούτε αποτέλεσμα ελέγχου, ούτε αναφορά, ούτε μήνυμα. Το CITSO, το προϊόν, εκτελείται εξ ολοκλήρου στις εγκαταστάσεις του πελάτη, εκτός σύνδεσης, χωρίς καμία σύνδεση με το GitHub ή με οποιαδήποτε διαδικτυακή υπηρεσία.

Όπως κάθε πάροχος φιλοξενίας, το GitHub μπορεί να καταγράφει τεχνικά τη διεύθυνση IP των επισκεπτών αυτού του ιστότοπου για την ασφάλεια της υπηρεσίας του, σύμφωνα με τη δική του πολιτική.
