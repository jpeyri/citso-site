Конфиденциальность

Этот сайт не устанавливает файлы cookie, не использует инструменты веб-аналитики, внешние шрифты или ресурсы и не содержит форм.

Если вы напишете нам на contact@citso.eu, ваше сообщение будет использовано только для ответа вам; оно не передается и не продается третьим лицам. Вы можете в любой момент запросить доступ к своим данным или их удаление по тому же адресу.

Роль GitHub

GitHub используется только для отображения этого публичного сайта. Он не получает никаких данных наших клиентов: ни каталога, ни результатов аудита, ни отчетов, ни сообщений. CITSO как продукт работает полностью у клиента, без подключения к сети, без какой-либо связи с GitHub или любым другим онлайн-сервисом.

Как и любой хостинг-провайдер, GitHub может в технических целях регистрировать IP-адреса посетителей этого сайта для обеспечения безопасности своего сервиса в соответствии со своей политикой.
