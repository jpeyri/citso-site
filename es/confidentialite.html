Privacidad

Este sitio no instala ninguna cookie, no utiliza ninguna herramienta de medición de audiencia ni ninguna fuente o recurso externo, y no contiene ningún formulario.

Si nos escribe a contact@citso.eu, su mensaje solo sirve para responderle; no se cede ni se vende. Puede solicitar en cualquier momento el acceso a sus datos o su supresión en la misma dirección.

Papel de GitHub

GitHub solo se utiliza para mostrar este sitio público. No recibe ningún dato de nuestros clientes: ni directorio, ni resultados de auditoría, ni informes, ni mensajes. CITSO, el producto, se ejecuta íntegramente en las instalaciones del cliente, fuera de línea, sin ninguna conexión con GitHub ni con ningún otro servicio en línea.

Como cualquier proveedor de alojamiento, GitHub puede registrar técnicamente la dirección IP de los visitantes de este sitio para la seguridad de su servicio, conforme a su propia política.
