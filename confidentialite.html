Confidentialité

Ce site ne dépose aucun cookie, n'utilise aucun outil de mesure d'audience, aucune police ni ressource externe, et ne contient aucun formulaire.

Si vous nous écrivez à contact@citso.eu, votre message sert uniquement à vous répondre ; il n'est ni cédé ni revendu. Vous pouvez demander à tout moment l'accès à vos données ou leur suppression à la même adresse.

Rôle de GitHub

GitHub n'est utilisé que pour l'affichage de ce site public. Il ne reçoit aucune donnée de nos clients : ni annuaire, ni résultat d'audit, ni rapport, ni message. CITSO, le produit, s'exécute entièrement chez le client, hors ligne, sans aucune connexion à GitHub ni à un quelconque service en ligne.

Comme tout hébergeur, GitHub peut journaliser techniquement l'adresse IP des visiteurs de ce site pour la sécurité de son service, selon sa propre politique.
