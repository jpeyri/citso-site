Datenschutz

Diese Website setzt keine Cookies, verwendet kein Werkzeug zur Reichweitenmessung, keine externen Schriftarten oder Ressourcen und enthält kein Formular.

Wenn Sie uns an contact@citso.eu schreiben, wird Ihre Nachricht ausschließlich zur Beantwortung verwendet; sie wird weder weitergegeben noch verkauft. Sie können jederzeit unter derselben Adresse Auskunft über Ihre Daten oder deren Löschung verlangen.

Rolle von GitHub

GitHub wird ausschließlich für die Anzeige dieser öffentlichen Website genutzt. Es erhält keinerlei Daten unserer Kunden: weder Verzeichnisdaten noch Auditergebnisse, Berichte oder Nachrichten. CITSO, das Produkt, läuft vollständig beim Kunden, offline, ohne jede Verbindung zu GitHub oder zu einem anderen Onlinedienst.

Wie jeder Hoster kann GitHub die IP-Adressen der Besucher dieser Website zur Sicherheit seines Dienstes technisch protokollieren, gemäß seiner eigenen Richtlinie.
