Privatumas

Ši svetainė neįrašo slapukų, nenaudoja lankomumo matavimo įrankių, išorinių šriftų ar kitų išorinių išteklių ir neturi jokių formų.

Jei parašysite mums adresu contact@citso.eu, jūsų žinutė bus naudojama tik atsakyti jums; ji nėra perduodama ar perparduodama. Bet kada tuo pačiu adresu galite paprašyti prieigos prie savo duomenų arba jų ištrynimo.

GitHub vaidmuo

GitHub naudojamas tik šiai viešai svetainei rodyti. Jis negauna jokių mūsų klientų duomenų: nei katalogo, nei audito rezultatų, nei ataskaitų, nei žinučių. CITSO produktas visiškai veikia kliento aplinkoje, neprisijungus, be jokio ryšio su GitHub ar kokia nors internetine paslauga.

Kaip ir bet kuris talpinimo paslaugų teikėjas, GitHub savo paslaugos saugumo tikslais gali techniškai registruoti šios svetainės lankytojų IP adresus pagal savo politiką.
