Integritet

Denna webbplats sätter inga kakor, använder inga verktyg för besöksmätning, inga externa typsnitt eller resurser och innehåller inga formulär.

Om ni skriver till oss på contact@citso.eu används ert meddelande enbart för att svara er; det lämnas inte ut och säljs inte vidare. Ni kan när som helst begära tillgång till era uppgifter eller att de raderas, via samma adress.

GitHubs roll

GitHub används enbart för att visa denna offentliga webbplats. Det tar inte emot några data från våra kunder: varken katalogdata, granskningsresultat, rapporter eller meddelanden. Produkten CITSO körs helt hos kunden, offline, utan någon anslutning till GitHub eller till någon annan onlinetjänst.

Som alla webbhotell kan GitHub av tekniska skäl logga besökarnas IP-adresser för säkerheten i sin tjänst, enligt sin egen policy.
