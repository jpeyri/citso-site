Prywatność

Ta strona nie zapisuje żadnych plików cookie, nie korzysta z narzędzi do pomiaru oglądalności, zewnętrznych czcionek ani zasobów i nie zawiera żadnych formularzy.

Jeśli napiszą Państwo do nas na adres contact@citso.eu, wiadomość posłuży wyłącznie do udzielenia odpowiedzi; nie jest przekazywana ani odsprzedawana. W każdej chwili mogą Państwo zażądać dostępu do swoich danych lub ich usunięcia, pisząc na ten sam adres.

Rola GitHub

GitHub służy wyłącznie do wyświetlania tej publicznej strony. Nie otrzymuje żadnych danych naszych klientów: ani katalogu, ani wyników audytu, ani raportów, ani wiadomości. CITSO, czyli produkt, działa w całości u klienta, offline, bez jakiegokolwiek połączenia z GitHub ani z jakąkolwiek usługą online.

Jak każdy dostawca hostingu, GitHub może technicznie rejestrować adresy IP odwiedzających tę stronę w celu zapewnienia bezpieczeństwa swojej usługi, zgodnie z własną polityką.
